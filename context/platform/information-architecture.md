# Information architecture

## Screen list

- **Work** (`/`, home page): cards for the projects ticked "Show on the Work page" (Experience records). Each card opens a case page at `/work/<slug>`.
- **Talks** (`/talks`), **Publications** (`/publications`): CMS pages filled from talk and publication records.
- **Thoughts** (`/thoughts`): the list of posts; each post at `/thoughts/<slug>`.
- **Resume** (`/resume`), **About** (`/about`): CMS pages.

## Navigation structure

Work · Talks · Publications · Thoughts · Resume · About (DD-001). Each item has a subtitle that reads on from its name ("Thoughts that came to mind"). The order follows Pages > order in the CMS.
